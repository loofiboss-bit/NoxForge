## Acceptance

Doctor covers components, portable/system, missing metadata, shadowing, conflicts,
missing active plugins and service timeouts without writes. Staged roots never
consult the host version or active settings. Text/JSON agree. Tests cover all
six existing scales, RTL, expanded labels, keyboard focus, no blur and reduced
motion. Actual rendered colors meet existing contrast limits. Package install,
reinstall, removal and rollback preserve desktop/login configuration bytewise.
Media paths, dimensions and provenance are checked; captures contain no personal
data. Physical login/PAM/audio/input/cursor/power and physical mixed displays
remain pending or blocked when unavailable, never inferred from offscreen runs.
