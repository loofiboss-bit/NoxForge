# NoxForge 21.0.5

NoxForge 21.0.5 is a comprehensive polish and bug-fix patch release for **v21** (*Duotone Visual Craft, Aurorae v2, Live Control Core & Ecosystem v4*) targeting Fedora 44/45 and Arch KDE Plasma 6.8+ and Qt 6.11 on Wayland.

## Fixes & Improvements

- **Native Qt 6 Style (`libnoxforge6.so`)**:
  - **Selected Item Contrast (`PE_PanelItemViewItem` / `PE_PanelItemViewRow`)**: Adapts selection background painting to `QPalette::HighlightedText` WCAG luminance, eliminating invisible dark-on-dark selected sidebar items in KDE System Settings, Discover, Dolphin, and QQC2/Kirigami apps while preserving the dark `surfaceSelected` + 3 px accent rail treatment when `HighlightedText` is light. Added leading text/icon inset in `subElementRect()` so text never touches the accent rail.
  - **SpinBox & ComboBox Sizing**: Expanded `CT_SpinBox` (+52 px) and `CT_ComboBox` (+54 px) horizontal margins, tuned `SC_SpinBoxEditField` spacing, and suppressed nested borders on frameless inner `QLineEdit`s (`lineWidth == 0`), fixing clipped values such as `100 %` and `50 %`.
  - **Checked Toggle & Flat Buttons**: Added visible `State_On` toggle state (dark `surfaceSelected`, accent border, Forge Notch, and 2 px bottom accent bar) so checkable buttons like Display Orientation clearly indicate active selection, and gave `Flat` / `AutoRaise` buttons a quiet resting look.
  - **Accent Parsing, Disabled Controls & Indicators**: Fixed `QSettings::IniFormat` comma-separated `QStringList` parsing for `AccentColor` in `kdeglobals`, muted disabled checkboxes/radios/sliders/progress bars, always rendered both SpinBox arrows, fixed `HasMenu` tool buttons, exclusive menu radio items, and indeterminate busy progress rendering.
- **Color Schemes, GTK 3/4, Plasma 6.8 Union CSS & Ecosystem**:
  - Upgraded `[Colors:Selection]` `ForegroundNegative`, `ForegroundNeutral`, and `ForegroundVisited` to WCAG AAA contrast on both Graphite and Obsidian.
  - Fixed GTK 3.0 & GTK 4.0 CSS (Obsidian `accent_ink`, removed invalid `checkbutton:checked`/`radiobutton:checked` container fills, added complete GTK 3 widget rules) verified with zero `Gtk.CssProvider` parsing errors.
  - Aligned Plasma 6.8 Union CSS selectors with real Union 6.8 element names (`scrollbar > handle`, `checkbox > indicator`, `switch > indicator > handle`, `slider`, `spinbox`, `card`, `inlinemessage`, `monthgrid`), added `--tooltip-*` tokens, and raised default-button hover/press contrast.
  - Fixed contrast and Obsidian parity in Kate, VS Code, Discord, Firefox, Obsidian.md, `git-delta`, and Plasma System Monitor.
- **Plasma SVGs, Aurorae v2, Icons, Cursors & Shared QML Surfaces**:
  - Fixed Plasma SVG margin hints, `hint-compose-over-border`, blur masks, `tasks.svg` attention opacity, `scrollbar`, `slider`, `switch`, `radiobutton`, and `checkmarks`.
  - Removed hard corner wedges in Aurorae `decoration.svg`, preserved red hover/press feedback on inactive `close.svg`, lit the first arc in `network-wireless-connected-25.svg`, and fixed Wayland scalable cursor hollow rings, hotspots, and `Inherits`.
  - Fixed `LockScreen.qml` `revealPassword` `TypeError` + Caps Lock `KeyState` + `authenticator` handling, `OsdItem.qml` >100% overdrive, `TabBox` layout & binding loop, `Logout`/`SystemDialog` keyboard shortcuts, `SDDM` null guards, and Obsidian Look-and-Feel `TabBox` default.
- **CLI, Control Center, Doctor & Packaging**:
  - Fixed `noxforge-ctl` (`@import` ordering before user GTK rules, live `plasma-apply-colorscheme` ordering with `-a <hex>`, Union full-mode preservation, stale local Aurorae refresh, dual-profile Aurorae accent sync, quoted schedule presets, RPM `fastfetch` asset path, sibling binary discovery).
  - Fixed `control_center.py`, `opacity_gui.py` (`--gui` forwarding), `noxforge_core.py`, `scripts/uninstall.sh`, `packaging/noxforge.spec` (`Requires: python3`), and `noxforge-doctor` (shadowing `libnoxforge6.so` detection across `$QT_PLUGIN_PATH`, `~/.local/lib*`, `/usr/local/lib*`, and `.svgz` Aurorae customization recognition).

## Fedora installation

Install or upgrade signed RPM packages from the [COPR repository](https://copr.fedorainfracloud.org/coprs/loofitheboss/noxforge/):

```bash
sudo dnf copr enable loofitheboss/noxforge
sudo dnf upgrade --refresh noxforge   # or: sudo dnf install --refresh noxforge
rpm -V noxforge
noxforge-ctl sync
noxforge-doctor --json
```

## Portable installation

Download `noxforge-21.0.5-portable.tar.xz` and `SHA256SUMS` from the release assets:

```bash
sha256sum -c SHA256SUMS --ignore-missing
tar -xJf noxforge-21.0.5-portable.tar.xz
cd noxforge
./scripts/install.sh --user --dry-run
./scripts/install.sh --user
```
