# NoxForge 15.0.0 — Kinetic Signal & Adaptive Motion Suite

NoxForge 15.0.0 delivers living, kinesthetically responsive desktop motion across KDE Plasma 6, SDDM, and Qt 6. This release introduces FreeDesktop / KDE current-color-scheme vector iconography, a multi-stage geometric Wi-Fi and signal family, dual-concentric orbital radar busy indicators, 220ms damped horizontal authentication error-shake, a live icon and motion preview canvas in the Control Center GUI, and Doctor Schema 8 diagnostics.

---

## Highlights

### 1. Adaptive FreeDesktop / KDE Current-Color-Scheme Iconography
- **Native Color-Scheme Integration**: Embedded `<style id="current-color-scheme">` across all 201 scalable SVGs and 288 optical variants (16x16 and 22x22).
- **Dynamic System Adaptation**: `ColorScheme-Text`, `ColorScheme-Highlight`, `ColorScheme-NeutralText`, and `ColorScheme-NegativeText` react natively and immediately to active Plasma color palettes.

### 2. Multi-Stage Geometric Wi-Fi & Signal Family
- **High-Precision Vector Geometry**: Replaced fallback degradation with mathematical 24px geometric curves:
  - Signal tiers: 0% (`network-wireless-connected-00`), 25% (`connected-25`), 50% (`connected-50`), 75% (`connected-75`), and 100% (`connected-100`).
  - Specialized states: `network-wireless-acquiring`, `network-wireless-locked`, `network-wireless-hotspot`, and `network-wireless-disconnected` (featuring a clean 45° Forge Notch negative slash).
  - Battery indicators: `battery-000` and `battery-100` glyphs with charging cues.

### 3. Dual-Ring Orbital Radar Busy Widget
- **Upgraded `busywidget.svg`**: Overhauled across both Graphite and Obsidian desktop themes into dual concentric orbital radar arcs with accented rotational lead.

### 4. Kinetic Motion Polish Across Plasma Surfaces
- **Wayland Lock Screen**: Integrated 220ms damped horizontal error-shake (`errorShakeAnim`, +/-8px -> +/-4px -> 0px) on authentication failure in `LockScreen.qml` across Graphite and Obsidian variants. Added live network and battery status badges.
- **SDDM Login Theme**: Smooth password rejection shake and responsive focus transitions in `Main.qml`.
- **KWin Window Switcher**: Fluid bezier curves, tactile card elevation (`scale: 1.04`), and expanding accent indicator bar.

### 5. Control Center GUI Live Visual Hub
- **Live Icon & Motion Preview Canvas**: Interactive panel previewing Wi-Fi signal tiers, battery levels, and audio indicators reflecting active accent colors (Lime, Cyan, Violet, Amber).
- **Interactive Motion Trigger**: Direct test trigger for the 220ms kinetic error-shake spring animation.

### 6. Diagnostics & Automated Contracts
- **Doctor Schema 8**: Upgraded `noxforge-doctor` with automated `iconAdaptation` audit, validating adaptive SVG headers, signal tier coverage, and palette coherence.
- **Automated Contracts**: Complete automated test suite in `tests/test_v15_contracts.py` covering all v15 release gates.

## Installation & Verification

### Fedora 44 (COPR)

```bash
sudo dnf copr enable loofitheboss/noxforge
sudo dnf install --refresh noxforge
noxforge-ctl status
```

### Portable Edition (User-Local)

Download `noxforge-15.0.0-portable.tar.xz` and `SHA256SUMS` from the [GitHub Release](https://github.com/loofiboss-bit/NoxForge/releases/tag/v15.0.0):

```bash
tar -xJf noxforge-15.0.0-portable.tar.xz
cd noxforge
./scripts/install.sh --user
noxforge-doctor --json
```

### Arch Linux

```bash
export SRCDEST="$(mktemp -d)"
cp noxforge-15.0.0-source.tar.xz "$SRCDEST/"
makepkg --verifysource --cleanbuild
makepkg --cleanbuild
```
