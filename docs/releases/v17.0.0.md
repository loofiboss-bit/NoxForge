# NoxForge 17.0.0 — Total Single-Source Authority, Dynamic Accent Ecosystem & Portable Integrity

NoxForge 17.0.0 advances the Linux visual system with comprehensive single-source authority, non-lime accent harmonization, enhanced authentication security policies, developer ecosystem orchestration, and verified portable integrity for KDE Plasma 6.7+, SDDM, and Qt 6.11 on Wayland.

---

## Highlights

### 1. Total Single-Source Authority (Schema 2)
- **Universal Single Sources**: Extended canonical shared source templates under `qml/shared/` to encompass:
  - Wayland Lock Screen: `qml/shared/lockscreen/LockScreen.qml`
  - SDDM Greeters: `qml/shared/sddm/Main.qml`
  - KWin TabBox Window Switcher: `qml/shared/tabbox/main.qml`
  - Splash Screen: `qml/shared/splash/Splash.qml`
  - Logout Greeter: `qml/shared/logout/Logout.qml`
- **Single-Source Generator**: Upgraded `design/qml-variants.json` and `scripts/generate_design_system.py` to compile 10 variant files across Graphite and Obsidian surfaces with byte-for-byte reproducibility.
- **Drift Prevention**: Integrated bidirectional verification into `scripts/validate.py` and `tests/test_qml_variants.py`.

### 2. Dynamic Accent Harmonization
- **True Palette Harmony**: Extended non-lime accent harmonization (Electric Lime, Forge Cyan, Cyber Violet, Molten Amber, and validated custom colors) across:
  - Native Qt 6 C++ style plugin (`plugins/styles/noxforge.cpp`)
  - Command-line controller (`tools/noxforge-ctl`)
  - Multi-tab Control Center (`tools/control_center.py`)
- **Accent Consistency**: Window focus indicators, highlights, scrollbars, sliders, notches, and TabBox frames dynamically align with the selected active accent.

### 3. Password Security Policies & Indicators
- **Secure Default**: Enforced `allowEmptyPassword=false` default across Lock Screen and SDDM greeters to prevent accidental unlock cycles on headless or unconfigured credentials.
- **Visual Feedback**: Added clear visual indicators for password reveal states and authentication errors while honoring reduced motion guidelines.

### 4. Developer Ecosystem & CLI Orchestration
- **Ecosystem Subcommands**: Introduced `noxforge-ctl ecosystem [status|apply|sync|list]` for seamless theme deployment across:
  - Terminals: Ghostty, Alacritty, Kitty, Foot
  - Editors: Neovim (Lua), Helix (TOML), Zed (JSON)
  - Shell & Monitoring: Starship prompt, Fastfetch preset, btop
  - Browsers & Communication: Firefox CSS (userChrome), Discord / Vesktop
- **Configurable Diurnal Scheduling**: Enhanced `noxforge-ctl schedule` with custom transition boundaries (`--day-time` and `--night-time`).

### 5. Unified Control Center Tab 5 & Doctor Schema 10
- **Ecosystem & Apps Tab**: New dedicated 5th tab in `tools/control_center.py` providing one-click ecosystem application status inspection and theme synchronization.
- **Doctor Schema 10**: Upgraded `tools/noxforge-doctor` with:
  - Universal QML variant drift detection across all 10 single-source targets
  - Terminal and developer tool theme alignment audits
  - Systemd user timer verification and palette synchronization receipts.

## Installation & Verification

### Fedora 44 (COPR)

```bash
sudo dnf copr enable loofitheboss/noxforge
sudo dnf install --refresh noxforge
noxforge-ctl status
```

### Portable Edition (User-Local)

Download `noxforge-17.0.0-portable.tar.xz` and `SHA256SUMS` from the GitHub Release:

```bash
tar -xJf noxforge-17.0.0-portable.tar.xz
cd noxforge
./scripts/install.sh --user
noxforge-doctor --json
```

### Diagnostics & Health Check

```bash
noxforge-doctor
noxforge-ctl status
noxforge-ctl ecosystem status
```
