# NoxForge 21.0.3

NoxForge 21.0.3 is a focused usability and CSS-conformance patch release for **v21** (*Duotone Visual Craft, Aurorae v2, Live Control Core & Ecosystem v4*) targeting Fedora 44/45 and Arch KDE Plasma 6.8+ and Qt 6.11 on Wayland.

## Fixes & Improvements

- **Fix Near-Invisible Text Selection in Plasma & KDE Color Schemes (`[Colors:Selection]`)**:
  - Updated `color_scheme_for_palette()` in `scripts/generate_design_system.py` so `NoxForgeDark.colors`, `NoxForgeObsidian.colors`, and the embedded Plasma Desktop Theme `colors` files (`io.github.loofiboss.noxforge.desktop` and `io.github.loofiboss.noxforge.obsidian.desktop`) use high-contrast `accentPressed` (`#82D936`) selection fills with dark ink (`#0D1419` on Graphite, `#000000` on Obsidian) and matching dark active/inactive/link/positive selection foregrounds.
  - Raises text-selection contrast against sunken Plasma input fields (`#10191F`, e.g. Kickoff search and `PlasmaComponents3.TextField`) from `1.35:1` to `10.10:1`, while maintaining WCAG AAA text contrast (`10.54:1` Graphite / `11.93:1` Obsidian).
- **Fix GTK 3 & GTK 4 CSS Parsing Error (`::selection`)**:
  - Removed the unsupported web CSS pseudo-element `::selection` from generated `themes/NoxForge/gtk-{3.0,4.0}/gtk.css` and `themes/NoxForgeObsidian/gtk-{3.0,4.0}/gtk.css`, preserving valid GTK node selectors (`selection, entry selection, textview text selection, label selection`).
  - Eliminates `Theme parsing error: gtk.css: Invalid name of pseudo-class` in GTK 3/4 applications (such as `setroubleshoot` / `sealert`) and ensures selection rules apply cleanly with zero parser errors.

## Fedora installation

Install or upgrade signed RPM packages from the [COPR repository](https://copr.fedorainfracloud.org/coprs/loofitheboss/noxforge/):

```bash
sudo dnf copr enable loofitheboss/noxforge
sudo dnf upgrade --refresh noxforge   # or: sudo dnf install --refresh noxforge
rpm -V noxforge
noxforge-ctl sync
noxforge-doctor --json
```

## Portable installation

Download `noxforge-21.0.3-portable.tar.xz` and `SHA256SUMS` from the release assets:

```bash
sha256sum -c SHA256SUMS --ignore-missing
tar -xJf noxforge-21.0.3-portable.tar.xz
cd noxforge
./scripts/install.sh --user --dry-run
./scripts/install.sh --user
```
