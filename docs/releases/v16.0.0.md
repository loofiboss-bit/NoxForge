# NoxForge 16.0.0 — Single Source, Kinetic Accessibility & Verified Truth

NoxForge 16.0.0 brings single-source authority, kinetic accessibility, guarded experimental biometric authentication, and a unified control center to KDE Plasma 6, SDDM, and Qt 6. This release replaces manual QML variant duplication with an automated generator pipeline, respects system reduced-motion preferences with static edge-flash fallbacks, enforces strict WCAG AA 4.5:1 custom accent contrast, introduces guarded LoofiFaceID login support, unifies desktop management into a multi-tab Control Center, and upgrades Doctor to Schema 9 diagnostics.

---

## Highlights

### 1. Single-Source QML Architecture & Drift-Proof Generator
- **Canonical Single Sources**: Established shared source templates under `qml/shared/` for:
  - Wayland Lock Screen: `qml/shared/lockscreen/LockScreen.qml`
  - SDDM Login Screen: `qml/shared/sddm/Main.qml`
  - KWin TabBox Window Switcher: `qml/shared/tabbox/main.qml`
- **Deterministic Generation**: Added `design/qml-variants.json` and generator in `scripts/generate_design_system.py` producing all 6 variant files across Graphite and Obsidian surfaces with byte-for-byte reproducibility.
- **Drift Prevention**: Integrated drift checks into `scripts/validate.py` and rolling unit tests in `tests/test_qml_variants.py`.

### 2. Kinetic Accessibility & Reduced Motion
- **System Motion Respect**: Automatically detects `Kirigami.Units.longDuration <= 0`, `AnimationDurationFactor <= 0`, or `NOXFORGE_REDUCED_MOTION=1`.
- **Static Edge-Flash Fallback**: Under reduced motion, password rejection spring shakes are cleanly replaced with a high-visibility 220ms static edge-flash indicator in `ColorScheme-NegativeText`.
- **Screen Reader Support**: Added semantic `Accessible.role`, `Accessible.name`, and `Accessible.description` tags across authentication inputs, error banners, and action buttons.
- **WCAG AA Contrast Enforcement**: `noxforge-ctl accent custom '#RRGGBB'` and Control Center calculate mathematical relative luminance and strictly require a minimum 4.5:1 contrast ratio against both Graphite (`#141E25`) and Obsidian (`#000000`) surfaces before applying.

### 3. Guarded Experimental LoofiFaceID Authentication
- **Opt-in Biometric Login**: Added non-invasive face-authentication hooks to SDDM (`Main.qml`) and Lock Screen (`LockScreen.qml`).
- **Guarded Invocation**: Checks `typeof sddm.registerFaceAuthenticationUi === "function"` and `typeof faceAuthenticator !== "undefined"`; cleanly falls back to password authentication when APIs or PAM modules are absent.
- **Non-Applying Boundary**: NoxForge installs no daemons, PAM configs, or system policies and never mutates desktop settings automatically.
- **Documentation**: Comprehensive specification in `docs/EXPERIMENTAL_FACE_AUTH.md`.

### 4. Unified Control Center GUI
- **Multi-Tab Interface** (`tools/control_center.py`):
  - **Profile & Palette**: Quick toggling between Graphite and Obsidian presets with system-wide reconfiguration.
  - **Opacity**: Interactive sliders and presets (Solid, Subtle, Glass, Vapor) for window and panel transparency.
  - **Accessibility & Motion**: Reduced-motion toggle simulation and real-time custom accent contrast calculator with WCAG AA compliance indicators.
  - **System Health**: Embedded Doctor diagnostic audit with instant refresh and copyable reports.
- **Compatibility**: Retained `tools/opacity_gui.py` as a lightweight launcher shim routing to `control_center.py --tab opacity`.
- **Headless Test Suite**: Full offscreen PySide6 testing in `tests/test_control_center_gui.py`.

### 5. Doctor Schema 9 & Authoritative Gates
- **Comprehensive Diagnostics**: Upgraded `tools/noxforge-doctor` to Schema 9 with new audits:
  - `qmlVariantDrift`: Verifies variant files match generated templates.
  - `reducedMotion`: Reports active motion policy and environment overrides.
  - `customAccentContrast`: Audits active custom accent contrast against graphite and obsidian canvases.
  - `faceAuthApi`: Reports status of SDDM configuration and PAM modules.
  - `versionCoherence`: Detects cross-component version divergences.
- **Fast Preflight CI**: New `<3m` preflight workflow in `.github/workflows/ci.yml` gating full pipelines on linting and rolling contract tests.
- **Test Optimization**: Archived 25 legacy test suites to `tests/archive/`, dropping test suite run times by >65%.

## Installation & Verification

### Fedora 44 (COPR)

```bash
sudo dnf copr enable loofitheboss/noxforge
sudo dnf install --refresh noxforge
noxforge-ctl status
```

### Portable Edition (User-Local)

Download `noxforge-16.0.0-portable.tar.xz` and `SHA256SUMS` from the GitHub Release:

```bash
tar -xJf noxforge-16.0.0-portable.tar.xz
cd noxforge
./scripts/install.sh --user
noxforge-doctor --json
```

### Diagnostics & Health Check

```bash
noxforge-doctor
noxforge-ctl status
```
