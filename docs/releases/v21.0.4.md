# NoxForge 21.0.4

NoxForge 21.0.4 is a focused user-safety patch release for **v21** (*Duotone Visual Craft, Aurorae v2, Live Control Core & Ecosystem v4*) targeting Fedora 44/45 and Arch KDE Plasma 6.8+ and Qt 6.11 on Wayland.

## Fixes & Improvements

- **Keep Fastfetch Strictly Opt-In (`tools/noxforge-ctl`)**:
  - Marked `fastfetch` with `opt_in: True` in `SUPPORTED_ECOSYSTEM_APPS` so bulk `noxforge-ctl ecosystem apply` / `ecosystem apply all` and Control Center's **Deploy All Detected Themes** never overwrite users' existing `~/.config/fastfetch/config.jsonc` or `logo.txt` automatically.
  - Users who want NoxForge's Fastfetch Kinetic Studio presets can still explicitly opt in via `noxforge-ctl fastfetch --preset <main|cyber|minimal>`, `noxforge-ctl ecosystem apply fastfetch`, or the dedicated Fastfetch preset selector in Control Center.
  - Fixed `fastfetch` installed-status detection to require NoxForge ownership in `ecosystem-state.json` instead of falsely marking any pre-existing user `config.jsonc` as synced.
  - Fixed stale `ecosystem-state.json` persistence in `ecosystem_apply()` and backup guarding in `manage_fastfetch()` so explicit Fastfetch opt-in is properly tracked and `noxforge-ctl ecosystem restore fastfetch` cleanly restores the original files.

## Fedora installation

Install or upgrade signed RPM packages from the [COPR repository](https://copr.fedorainfracloud.org/coprs/loofitheboss/noxforge/):

```bash
sudo dnf copr enable loofitheboss/noxforge
sudo dnf upgrade --refresh noxforge   # or: sudo dnf install --refresh noxforge
rpm -V noxforge
noxforge-ctl sync
noxforge-doctor --json
```

## Portable installation

Download `noxforge-21.0.4-portable.tar.xz` and `SHA256SUMS` from the release assets:

```bash
sha256sum -c SHA256SUMS --ignore-missing
tar -xJf noxforge-21.0.4-portable.tar.xz
cd noxforge
./scripts/install.sh --user --dry-run
./scripts/install.sh --user
```
