# NoxForge 14.0.0 — Unified Control Suite & Full Ecosystem Parity

NoxForge 14.0.0 delivers complete dual-stack architectural parity across the standard Graphite and Obsidian OLED palettes, introduces the unified NoxForge Control suite, refines Qt 6 dynamic styling, and expands official ecosystem themes across editors, terminals, and desktop applications.

---

## Highlights

### 1. True Obsidian OLED Parity & Dual-Stack Architecture
- **Dedicated Lock Screen**: Full Obsidian lock screen implementation (`io.github.loofiboss.noxforge.obsidian.desktop/contents/lockscreen/`) featuring pure OLED black backgrounds, centered clock/date typography, and high-contrast electric lime input rings.
- **Dedicated TabBox KWin Switcher**: Distinct Obsidian window switcher (`io.github.loofiboss.noxforge.obsidian.desktop`) providing seamless task switching with pitch-black translucent backgrounds.
- **Dynamic Accent Matrix**: Real-time accent tinting and active notch indicators across both Graphite and Obsidian surfaces (`Lime`, `Cyan`, `Violet`, `Amber`).

### 2. Qt 6 C++ Dynamic Styling Engine
- **Dynamic QMenu Geometry**: Intelligent action item margins, paddings, and font metrics preventing text clipping or label truncation across diverse font sizes, DPI settings, and fractional scaling factors (100% to 200%).
- **Dynamic Toggle Switches**: High-contrast indicator pills and smooth geometry transitions providing immediate visual feedback.

### 3. Unified Control Suite
- **`noxforge-ctl` Command-Line Interface**: Unified CLI command for profile switching (`switch`), accent color selection (`accent`), desktop status inspection (`status`), opacity configuration (`opacity`), diagnostics (`doctor`), and diurnal automation (`schedule`).
- **NoxForge Control Center GUI**: Modern PySide6/Qt 6 application featuring a 3-tab layout (Profiles & Accents, Opacity & Glass, Diagnostics & Automation) with live wallpaper blur simulation.
- **Automated Day/Night Scheduling**: Systemd user timer integration allowing automated diurnal transitions (Graphite by day, Obsidian at night).

### 4. Extended Ecosystem & App Parity
- **Code & Text Editors**: Official themes for Zed editor, VS Code/Cursor, Neovim, and Helix in both Graphite and Obsidian palettes.
- **Terminals & Prompts**: Dedicated configurations for btop system monitor, Starship prompt, Fastfetch system information, Konsole, and Kitty/Alacritty.
- **Desktop Applications**: Customized CSS styling for Firefox (`userChrome.css`) and Discord.

### 5. Diagnostics & System Integrity
- **Doctor Schema 7**: Upgraded diagnostics with `--apply-sync [graphite|obsidian]` for non-destructive alignment of desktop configuration entries.
- **Package Contracts**: Synchronized Fedora 44 RPM/SRPM, Arch Linux PKGBUILD, portable archive, and KDE Store companion packages.

## Installation & Verification

### Fedora 44 (COPR)

```bash
sudo dnf copr enable loofitheboss/noxforge
sudo dnf install --refresh noxforge
noxforge-ctl status
```

### Portable Edition (User-Local)

Download `noxforge-14.0.0-portable.tar.xz` and `SHA256SUMS` from the [GitHub Release](https://github.com/loofiboss-bit/NoxForge/releases/tag/v14.0.0):

```bash
tar -xJf noxforge-14.0.0-portable.tar.xz
cd noxforge
./scripts/install.sh --user
noxforge-doctor --json
```

### Arch Linux

```bash
export SRCDEST="$(mktemp -d)"
cp noxforge-14.0.0-source.tar.xz "$SRCDEST/"
makepkg --verifysource --cleanbuild
makepkg --cleanbuild
```
