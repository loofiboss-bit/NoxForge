# NoxForge 8.0.0 — Forge Identity

NoxForge 8.0.0 is the stable Forge Identity release for Fedora 44 and verified
Arch Plasma/KWin 6.7+ with Qt 6.11 on Wayland.

- Split the historical bundle into deterministic KDE Store component archives.
- Added Forge, Quiet, and Ultrawide wallpaper IDs while preserving `NoxForge`.
- Added the Breeze-default portable edition and edition-aware doctor JSON.
- Trimmed full historical image matrices from the current tree; V7 history and
  tags remain immutable.
- Added Fedora/Arch source contracts, budgets, checksums, and qualification
  policy.
- Published the exact manifest artifact set through the GitHub `v8.0.0` release
  and updated KDE Store product `2367662` with the V8 Global Theme package.

Unavailable physical cursor, audio routing, PAM/login, power, and live input
checks remain pending or blocked where the required isolated hardware/session is
unavailable; no offscreen result is presented as live proof.
