# NoxForge 21.0.1

NoxForge 21.0.1 is a visual-craft & runtime polish patch release for **v21** (*Duotone Visual Craft, Aurorae v2, Live Control Core & Ecosystem v4*) targeting Fedora 44/45 and Arch KDE Plasma 6.8+ and Qt 6.11 on Wayland.

## Fixes & Improvements

- **Preserve Original Icons for All Third-Party & External Apps**:
  - Removed all 52 third-party and external KDE app overrides from `icons/NoxForge/{scalable,32x32,48x48,64x64}/apps/` (`firefox`, `vlc`, `steam`, `discord`, `org.telegram.desktop`, `com.bitwarden.desktop`, `gimp`, `org.kde.dolphin`, `code`, `spotify`, etc.), keeping only NoxForge's own 4 app icons (`noxforge-controlcenter` and `noxforge-opacity`).
  - Every other application now displays its authentic upstream icon cleanly via `Inherits=breeze-dark,breeze,hicolor`, while system folders (`places/`, incl. 6 accent folders), `mimetypes/`, toolbars, and panel/tray status icons retain NoxForge's Duotone & Kinetic visual language (**430 scalable + 896 optical icons**).
- **Fix Transparent Maximized Aurorae v2 Titlebars & `KF6Svg` Custom Style Stripping**:
  - Split custom `.ColorScheme-Raised`, `.ColorScheme-Sunken`, `.ColorScheme-Hover`, `.ColorScheme-Pressed`, and `.NoxForge-*` rules into dedicated `<style id="noxforge-decoration-style">`, `<style id="noxforge-button-style">`, and `<style id="noxforge-plasma-style">` blocks outside `<style id="current-color-scheme">` so KDE Plasma 6's `KF6Svg` never strips Graphite/Obsidian surfaces or `#4B606A` edge highlights to black while keeping dynamic accent substitution intact.
  - Added dedicated `decoration-maximized-inactive` frames so both active and inactive maximized windows render solid, opaque titlebars with zero desktop bleed-through.
- **Automatic `ksvg-elements` & `icon-cache.kcache` Invalidation on Live Reload**:
  - Updated `noxforge-ctl` (`reload_running_apps`) and `noxforge-opacity` to purge `~/.cache/ksvg-elements`, `~/.cache/icon-cache.kcache`, and orphaned user `icon-theme.cache` files and emit `KGlobalSettings` `IconChanged` (`notifyChange 4 0`) alongside `PaletteChanged` so RPM upgrades take effect immediately without stale cached elements.

## Fedora installation

Install or upgrade signed RPM packages from the [COPR repository](https://copr.fedorainfracloud.org/coprs/loofitheboss/noxforge/):

```bash
sudo dnf copr enable loofitheboss/noxforge
sudo dnf upgrade --refresh noxforge   # or: sudo dnf install --refresh noxforge
rpm -V noxforge
noxforge-ctl sync
noxforge-doctor --json
```

## Portable installation

Download `noxforge-21.0.1-portable.tar.xz` and `SHA256SUMS` from the release assets:

```bash
sha256sum -c SHA256SUMS --ignore-missing
tar -xJf noxforge-21.0.1-portable.tar.xz
cd noxforge
./scripts/install.sh --user --dry-run
./scripts/install.sh --user
```
