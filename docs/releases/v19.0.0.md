# NoxForge 19.0.0 — KDE Plasma 6.8 Union Style Engine, KWin CSD & Wayland Precision

NoxForge 19.0.0 delivers the KDE Plasma 6.8 Union Style Engine (`plasma-union`) with deterministic generation of `union/styles/noxforge` and `union/styles/noxforge-obsidian` via Tokens Schema 15, dynamic `custom-color("kcolorscheme", ...)` CSS variable bindings, hybrid Union orchestration in `noxforge-ctl union`, reversible KWin 6.8 client-side decoration window rules (`noxforge-ctl kwin-csd`), Plasma 6.8 System Monitor telemetry preset, Control Center v4 with wallpaper live thumbnail preview and real-time WCAG AAA/AA palette and contrast swatch bar, native themes for Obsidian.md and Rofi/Wofi, shell tab completion (`noxforge-ctl completion`), strict Fastfetch preservation, and Doctor Schema 12 diagnostics for KDE Plasma 6.8+ on Wayland across Fedora 44, Fedora 45, and Arch Linux.

---

## Highlights

### 1. KDE Plasma 6.8 Union Style Engine (`plasma-union`)
- **Deterministic Generation**: Generated `union/styles/noxforge` (Graphite) and `union/styles/noxforge-obsidian` (Obsidian OLED) in `scripts/generate_design_system.py` using Union CSS (`custom-color("kcolorscheme", ...)` and `:is(button, toolbutton, menubaritem, tabbutton)`).
- **Hybrid Orchestration**: `noxforge-ctl switch`, `apply`, and `sync` always synchronize `unionStyle` in `kdeglobals` (`[KDE]`), while `noxforge-ctl union [--enable|--disable|--status|--profile <graphite|obsidian>]` toggles full `widgetStyle=Union` mode vs native `libnoxforge6.so`.

### 2. Plasma 6.8 Wayland Precision & KWin 6.8 CSD
- **Platform Baseline**: Raised platform baseline to Plasma/KWin 6.8+ on Wayland across `packaging/noxforge.spec`, `packaging/arch/PKGBUILD`, and `distribution/release-manifest.json`.
- **Reversible KWin CSD Window Rules**: Added `noxforge-ctl kwin-csd [--enable|--disable|--status]` for synchronized client-side decoration rules in `~/.config/kwinrulesrc`.
- **System Monitor Telemetry Preset**: Added `apps/systemmonitor/noxforge-telemetry.page` featuring `gpu/all/usedVramPercentage` sensor integration.

### 3. User Configuration Preservation
- **Strict Fastfetch Preservation**: Fastfetch configuration is strictly preserved and never modified automatically by NoxForge, respecting user-defined ASCII logos and fetch modules.

### 4. Control Center v4, Tokens Schema 15 & Doctor Schema 12
- **Control Center v4**: Upgraded `tools/control_center.py` with wallpaper live thumbnail preview, real-time WCAG AAA/AA palette and contrast swatch bar, scrollable responsive layout, and `Union 6.8` / `Wayland 6.8` health badges.
- **Tokens Schema 15**: Codified Union style engine CSS bindings and telemetry contracts.
- **Doctor Schema 12**: Upgraded `tools/noxforge-doctor` with `unionStyleStatus`, `waylandCompositor`, and eliminated all `metadata-unknown` warnings on real installations.

### 5. Expanded Supported Ecosystem
- **Obsidian.md & Rofi/Wofi**: Native themes for Obsidian.md (`apps/obsidian/`) and Rofi/Wofi (`apps/rofi/`).
- **Shell Tab Completion**: Added `noxforge-ctl completion [bash|zsh|fish]` for seamless shell tab completion.
- **Multi-Distribution Support**: Added Fedora 45 verification and COPR packaging alongside Fedora 44 and Arch Linux.

## Installation & Verification

### Fedora 44 & Fedora 45 (COPR)

```bash
sudo dnf copr enable loofitheboss/noxforge
sudo dnf install --refresh noxforge
noxforge-ctl status
noxforge-doctor
```

### Portable Edition (User-Local)

Download `noxforge-19.0.0-portable.tar.xz` and `SHA256SUMS` from the GitHub Release:

```bash
tar -xJf noxforge-19.0.0-portable.tar.xz
cd noxforge-19.0.0-portable
./install.sh
noxforge-ctl status
```
