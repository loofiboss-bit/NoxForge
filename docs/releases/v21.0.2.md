# NoxForge 21.0.2

NoxForge 21.0.2 is a precision visual-craft & Qt 6 / Aurorae v2 border-polish patch release for **v21** (*Duotone Visual Craft, Aurorae v2, Live Control Core & Ecosystem v4*) targeting Fedora 44/45 and Arch KDE Plasma 6.8+ and Qt 6.11 on Wayland.

## Fixes & Improvements

- **Fix Dolphin Dock Separator Green Dot & Splitter Metrics (`libnoxforge6.so`)**:
  - Fixed the inverted `State_Horizontal` orientation in `PE_IndicatorDockWidgetResizeHandle` (which had clipped a 3-dot grip horizontally across a narrow vertical dock divider, leaving a single floating lime-green pixel in Dolphin between *Places* and the file grid).
  - Replaced floating dock separator dots with a razor-clean 1 px structural divider (`PM_DockWidgetSeparatorExtent = 1`, matching KDE Breeze) using `border` (`#2F414B`) and subtle `edgeHighlight` (`#4B606A`) on hover, and set `PM_SplitterWidth = 4` so `QSplitter` panes are cleanly draggable.
- **Fix Aurorae v2 Floating Window Borders, Top-Edge Tiling & Corner Artifacts**:
  - Added `hint-stretch-borders` and removed the partial accent segment inside `decoration-top` that previously tiled every 28 px into a dashed green pattern along floating window titlebars.
  - Placed the signature 1 px **Forge Notch** accent chamfer cleanly inside the fixed `decoration-topleft` corner (never tiles or stretches, still responds to `noxforge-ctl accent`).
  - Anchored all 36 9-patch cell bounding boxes (`decoration`, `decoration-inactive`, `decoration-maximized`, `decoration-maximized-inactive`) to exact integer pixel dimensions (`0.00 px` mismatch) and replaced hard-edged stepped shadow rectangles with seamless filter-free `<linearGradient>` / `<radialGradient>` ambient shadows (zero corner step tabs, zero `<filter>`).
  - Refined floating window side and bottom frames from a thick `6 px` slab to a sleek modern `2 px` bezel (`BorderLeft=2`, `BorderRight=2`, `BorderBottom=2`) with matching `2 px` outer bottom corners while retaining full `PaddingLeft=12, PaddingRight=12, PaddingTop=8, PaddingBottom=16` ambient shadow and extended resize grab area.
- **Fix `0.5 px` Corner Bleed in Plasma Desktop Theme SVGs**:
  - Replaced `stroke-width="1"` top-corner highlight arcs in `scripts/generate_plasma_svgs.py` with exact 1 px filled corner rings so `dialogs/background.svg`, `widgets/panel-background.svg`, and `widgets/tooltip.svg` measure exact `6.00 × 6.00` corner bounds with zero `-0.5 px` subpixel blur.
- **Fix `.svgz` Sync in `noxforge-ctl` & `noxforge-opacity`**:
  - Both `sync_aurorae_accent()` (`tools/noxforge-ctl`) and `apply_opacity()` (`tools/noxforge-opacity`) now regenerate `decoration.svgz` alongside `decoration.svg` so KWin 6.8 immediately applies user-local Aurorae accent and opacity changes.

## Fedora installation

Install or upgrade signed RPM packages from the [COPR repository](https://copr.fedorainfracloud.org/coprs/loofitheboss/noxforge/):

```bash
sudo dnf copr enable loofitheboss/noxforge
sudo dnf upgrade --refresh noxforge   # or: sudo dnf install --refresh noxforge
rpm -V noxforge
noxforge-ctl sync
noxforge-doctor --json
```

## Portable installation

Download `noxforge-21.0.2-portable.tar.xz` and `SHA256SUMS` from the release assets:

```bash
sha256sum -c SHA256SUMS --ignore-missing
tar -xJf noxforge-21.0.2-portable.tar.xz
cd noxforge
./scripts/install.sh --user --dry-run
./scripts/install.sh --user
```
