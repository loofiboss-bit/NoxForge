# NoxForge 9.0.0 — System Coherence

NoxForge 9.0.0 aligns Fedora 44 with
Plasma Login Manager while retaining SDDM as a compatibility component.

## Highlights

- Added manifest schema 2 and explicit Fedora PLM / Arch SDDM compatibility.
- Added doctor JSON schema 2 with a stable, read-only `loginSurface` report.
- Added PLM wallpaper precedence and bounded system-service detection.
- Refined graphite surface hierarchy across Plasma and Qt from token schema 6.
- Added physical 16/22 px icons for Dolphin places and System Settings.
- Kept NoxForge Quiet as the recommended PLM wallpaper without adding a custom
  greeter or writing active login-manager configuration.
- Removed the Fedora package recommendation for SDDM; installation never
  installs, enables, disables, or switches a display manager.

## Qualification boundary

Automated package, source, visual, doctor, accessibility, sanitizer, QML, and
migration gates are recorded under `docs/evidence/v9/`. Physical login, PAM,
input, audio, power, cursor, and multi-monitor qualification remains `pending`
unless performed in an isolated real session. Automated evidence attached to
the GitHub release is bound to the exact tagged candidate commit.
