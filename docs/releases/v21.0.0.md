# NoxForge 21.0.0

NoxForge 21.0.0 (**Duotone Visual Craft, Aurorae v2, Live Control Core & Ecosystem v4**) is an original MIT-licensed visual system for Fedora 44/45 and Arch KDE Plasma 6.8+ and Qt 6.11 on Wayland.

## Highlights

- **Duotone Surface Iconography & Scalable Cursors**:
  - **482 scalable SVGs** (`56` curated app icons, `30` distinct mimetypes, `28` duotone & 6-accent places) and **1,052 optical variants** across `16x16`/`22x22` (crisp monoline) and `32x32`/`48x48`/`64x64` (Duotone Surface with inner bevel and chamfered Forge Notch), plus 6 accent folder variants (`lime`, `cyan`, `violet`, `amber`, `crimson`, `ice`).
  - **Wayland Scalable Cursors**: 96 4× supersampled Xcursors across `[24, 32, 36, 48, 64]` with a `1 px` dark contrast halo plus Plasma 6 `cursors_scalable/` (`368` verified cursor artifacts, zero symlinks).
  - **Tactile Forge Audio v2**: 27 distinct DSP WAV sources synthesized into 32 OGG Vorbis Freedesktop sound events.
  - **True PNG24 Wallpapers & Dynamic Day/Night**: Eliminated `PNG8` banding across 46 deterministic PNG24 assets, adding `16:10` (`2560x1600`, `3840x2400`), `32:9` (`5120x1440`), Plasma 6 `images_dark/` dynamic wallpaper, enriched Obsidian depth, and accent-adaptive wallpaper rendering.
- **Aurorae v2, Plasma 6.8 Shell & Canonical OSD / SystemDialog QML**:
  - **Aurorae v2** for Graphite and Obsidian: `Shadow=true` with filter-free stepped ambient shadows (`PaddingTop=8`, `PaddingBottom=16`, `PaddingLeft=12`, `PaddingRight=12`), flush `decoration-maximized-*` frames (`TitleEdgeTopMaximized=0`), Plasma 6 `metadata.json`, and user-local live accent rail syncing.
  - Overhauled Plasma Desktop Theme widget SVGs (`notes`, `clock`, `calendar`, `analog_meter`, `glowbar`, `checkmarks`) and single-source Look-and-Feel `osd/{Osd,OsdItem}.qml` + `systemdialog/SystemDialog.qml` (`18` generated QML outputs, zero raw hex literals, clean `qmllint`).
- **Event-Driven Native Qt 6 Style, Modular Plasma 6.8 Union CSS & Differentiated GTK 3/4**:
  - Replaced the `1000 ms` polling timer in `libnoxforge6.so` with member-owned `QFileSystemWatcher` + `ApplicationPaletteChange` caching; added 6-accent + custom `QPalette::Accent` support and full painting for `CC_Dial`, `CC_MdiControls`, `CC_TitleBar`, `CC_Slider` tickmarks, `CC_SpinBox` button states, `CE_DockWidgetTitle`, `CE_RubberBand`, `CE_SizeGrip`, and item-view/toolbar primitives.
  - Split Plasma 6.8 Union CSS (`union/styles/noxforge{,-obsidian}`) into **10 modular imported sheets** and differentiated `gtk-3.0/gtk.css` vs deep Libadwaita `gtk-4.0/gtk.css`.
- **Live Control Core (`noxforge-ctl`) & Async Control Center v6**:
  - Live app hot-reload (`KGlobalSettings`, `KWin`, `gsettings`, current-UID `SIGUSR1` for Kitty/Foot/Ghostty, `tmux`, `nvim` RPC), **Wallpaper Accent Extractor** (`noxforge-ctl accent --from-wallpaper [--sync-wallpaper]`), **Named Presets** (`noxforge-ctl preset save|list|apply|delete`), **Fastfetch Kinetic Studio v2** (`noxforge-ctl fastfetch --preset main|cyber|minimal`), and Flatpak `xdg-data/icons:ro;xdg-data/cursors:ro;` overrides.
  - Non-blocking `CommandWorker(QThread)` Control Center v6 with native `"NoxForge"` QStyle dogfooding, true Obsidian `#000000` surface mode, 6-accent matrix, Named Presets Manager, Live Surface & Control Preview, and live Ecosystem search.
- **Ecosystem v4 (25 Apps) & Honest Doctor Schema 14**:
  - Expanded to **25 supported ecosystem apps**, adding **Bat**, **Delta**, **Fzf**, **Eza**, **Wofi**, Fastfetch Kinetic Studio v2 (`main`/`cyber`/`minimal` + ANSI logos), deepened Neovim (`140+` highlight groups), VS Code semantic highlighting, Firefox `userContent*.css` + Zen/LibreWolf detection, Discord/Vesktop/Equibop, and `starship-obsidian.toml`.
  - **Doctor Schema 14**: Removed blind `metadata_version()` fallback and added `qtStyleLoadable`, `kwinBlurStatus`, `gtkImportIntegrity`, `flatpakIconAccess`, `dayNightTimerStatus`, and `configDrift`.

## Fedora installation

Install RPM packages from the [COPR repository](https://copr.fedorainfracloud.org/coprs/loofitheboss/noxforge/):

```bash
sudo dnf copr enable loofitheboss/noxforge
sudo dnf install --refresh noxforge
rpm -V noxforge
noxforge-doctor --json
```

## Portable installation

Download `noxforge-21.0.0-portable.tar.xz` and `SHA256SUMS` from the release assets:

```bash
sha256sum -c SHA256SUMS --ignore-missing
tar -xJf noxforge-21.0.0-portable.tar.xz
cd noxforge
./scripts/install.sh --user --dry-run
./scripts/install.sh --user
```
