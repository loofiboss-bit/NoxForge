# NoxForge 6.0.0

NoxForge 6.0.0 evolves Industrial Precision into Kinetic Precision: a quieter,
more dimensional dark visual system with explicit state hierarchy and bounded
motion for Fedora KDE 44, Plasma/KWin 6.7+, Qt 6.11, and Wayland.

## Kinetic Precision

- Five graphite surface layers, neutral selected surfaces, precise lime focus
  and selection markers, and restrained cyan/violet semantic detail.
- A rebalanced N/F mark, forged-planes wallpaper, and exact Global Theme
  previews generated from original project sources.
- A native Qt motion controller for hover, press, checked, selection, and busy
  states using one shared timer with complete zero-duration behavior.
- Refined Plasma materials across all 43 source families without SVG filters,
  broad glow, or unsupported animation claims.
- Responsive SDDM, Splash, Logout, and TabBox compositions with shared motion
  policy, keyboard structure, RTL, long-text, empty, error, busy, and
  reduced-motion scenarios.
- A 26 px Aurorae titlebar, consistent window controls, reviewed
  high-visibility icons, and normalized 24/32/48 px cursor optics.

## Qualification

- 141 Python tests and 21 CTest cases.
- ASan/UBSan coverage for style discovery, motion lifecycle, 500-cycle stress,
  and Qt accessibility preference probing.
- Deterministic source-bound evidence for Qt, Plasma, sessions, Aurorae, icons,
  cursors, wallpaper, and brand.
- All 15 documented contrast pairs, non-color indicators, system-font
  behavior, keyboard structure, RTL, 100/125/140/200 percent rendering, and
  zero-duration reduced motion pass automated checks.
- Gallery startup, control rendering, and SDDM first-frame medians remain
  within ten percent of the immutable reviewed v5 baseline.
- The local source archive is byte-reproducible, and Fedora SRPM/RPM builds
  pass their own CTest suite and `rpmlint` with zero errors and warnings.

## Honest limitations

An isolated KWin/Plasma Wayland matrix passes Global Theme application, exact
panel preservation, all four panel edges, two-output placement, visible shell
fallback review, and real Qt composition at 140 percent. The real windowed
Logout greeter and SDDM test mode also render NoxForge. The virtual framebuffer
cannot prove hardware-composited blur, and the environment has no trusted input
injector for complete motion, held Alt+Tab, cursor scaling, or interactive
Aurorae/Logout states. Production splash integration, live high-contrast mode,
PAM authentication, and real SDDM power actions remain explicitly blocked.
Offscreen evidence is not live evidence.

## Installation and rollback

Enable `loofitheboss/noxforge` on Fedora 44, install `noxforge`, then run
`rpm -V noxforge` and `noxforge-doctor`. Package
installation and removal do not apply the theme, change panels, activate SDDM,
clear caches, or restart Plasma. Select NoxForge explicitly, and select a
known-good Global Theme and SDDM configuration before removal.
