# NoxForge 4.0.0

NoxForge 4.0.0 delivers refined Qt 6 C++ native control rendering, Plasma 6 QML session surface enhancements, upgraded `noxforge-doctor` diagnostics, and expanded icon coverage under the **Industrial Precision** design system.

## Distribution status

The `v4.0.0` tag resolves to
`e3faefd481026cffafb9b48e11aa79987781fa78`. A public GitHub release exists,
but it was published without attached source, RPM, checksum or qualification
assets. No v4 COPR build or fresh v4 live qualification is claimed. The
completed v3 evidence remains historical and is not relabeled as v4 evidence.

## Qt 6 Style & Control Enhancements

- **Tab Bars (`QTabBar`)**: Distinct 4px Forge Notch accent rendering, `#202C34` hover feedback, and Electric Lime active tab indicators.
- **Header Views (`QHeaderView`)**: Deep graphite `#141B21` background, `#2B3942` hairline dividers, and interactive hover feedback.
- **Sliders & Scrollbars (`QSlider` / `QScrollBar`)**: Electric Lime focus rings, highlighted grooves, and active press state transitions (`#82D936`).

## Session Surfaces & QML Refinements

- Added 2px Electric Lime focus rings and crisp keyboard navigation indicators across SDDM, Splash, Logout, and KWin Window Switcher (`TabBox`).
- Verified QML compliance via `qmllint`.

## Diagnostics & Tooling

- `noxforge-doctor` support for machine-readable `--json` output and installation version mismatch detection.

## Icon & Visual Assets

- Generated 166 scalable vector icons and 172 optical size variants (16px & 22px).
- Added icons for display settings, keyboard preferences, offline status, and edit selections.

## Local verification

- Verified against Fedora 44, Plasma 6.7+, Qt 6.11, and Ninja build tools.
- Passed 54 Python unit tests and 11 C++ CTest probe tests with 100% pass rate.
