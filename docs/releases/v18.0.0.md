# NoxForge 18.0.0 — Libadwaita Parity, Reversible Ecosystem Engine v2 & Dynamic Control Core

NoxForge 18.0.0 advances the Linux visual system with comprehensive Libadwaita and GTK 3/4 CSS variable chaining, opt-in Flatpak theme override orchestration, a stateful and reversible Ecosystem Engine v2 with automatic `.noxforge.bak` backups, a unified shared core runtime library (`tools/noxforge_core.py`), real-time self-theming across the Unified Control Center GUI suite, and Doctor Schema 11 validation for KDE Plasma 6.7+, SDDM, and Qt 6.11 on Wayland.

---

## Highlights

### 1. Tokens Schema 14 & Baseline Quality
- **Schema 14 Contract**: Upgraded `design/tokens.json` to Schema 14, codifying the GTK dynamic CSS variable contract (`dynamicCssVariables: true`, `managedUserImport: true`) and the ecosystem state and backup contract (`syncPolicy: "stateful-reversible"`, `backupSuffix: ".noxforge.bak"`, `stateFile: "noxforge/ecosystem-state.json"`).
- **Code Hygiene**: Integrated flattened event dispatch and decoupled handlers in `tools/noxforge-live-input.cpp` and complete accessibility name annotations (`AccessibleName`) across GUI time and color inputs.

### 2. GTK 3/4, Libadwaita & Flatpak Parity
- **Dynamic CSS Variable Chaining**: Upgraded `generate_design_system.py` so interactive and focus selectors (`button:focus`, `button.suggested-action`, `entry:focus`, `checkbutton:checked`, `switch:checked`, `progressbar progress`, `scale highlight`, and selection states) bind to `@accent_color`, `@accent_bg_color`, `@accent_fg_color`, and `@theme_selected_bg_color` instead of static hex literals.
- **Managed Chaining Pipeline**: Replaced partial GTK overrides with a managed non-destructive `@import` + `@define-color` pipeline in `~/.config/gtk-3.0/gtk.css` and `~/.config/gtk-4.0/gtk.css`, ensuring GTK 4 / Libadwaita applications adopt both the active NoxForge surface (`NoxForge` or `NoxForgeObsidian`) and active accent override in real time.
- **Flatpak Theme Overrides**: Added opt-in Flatpak theme override orchestration (`noxforge-ctl flatpak --enable|--disable|--status`) and an interactive Control Center card covering `xdg-data/themes:ro`, `xdg-config/gtk-3.0:ro`, and `xdg-config/gtk-4.0:ro`.

### 3. Reversible & Reactive Ecosystem Engine v2
- **Automatic Backups & Reversibility**: Added automatic non-destructive backup creation (`<file>.noxforge.bak`) prior to deploying ecosystem configurations (`starship.toml`, `fastfetch/config.jsonc`, Firefox `userChrome.css`, etc.) and introduced `noxforge-ctl ecosystem restore [apps...|all]`.
- **Stateful Deployment Tracking**: Tracks deployed ecosystem targets in `~/.config/noxforge/ecosystem-state.json`.
- **Reactive Propagation**: Automatically propagates both profile switches (`graphite` <-> `obsidian`) and accent overrides (`lime`, `cyan`, `violet`, `amber`, or custom WCAG AA `#RRGGBB`) into all deployed ecosystem applications (Firefox, Starship, Fastfetch, Discord, btop, Zed, Ghostty, Kitty, Alacritty, Foot) and active Konsole profiles on `noxforge-ctl switch`, `apply`, `sync`, or `accent`.

### 4. Shared Core Library (`tools/noxforge_core.py`) & Control Center v3
- **Unified Core Runtime**: Extracted `tools/noxforge_core.py` (installed across portable, RPM, and Arch packages) to unify version lookup, XDG path resolution, `kreadconfig6`/`kwriteconfig6` wrappers, WCAG 2.1 contrast calculation, and dynamic Qt stylesheet generation.
- **Dynamic Self-Theming**: Upgraded `tools/control_center.py` and `tools/opacity_gui.py` with live self-theming (`build_qt_stylesheet(profile, accent_hex)`), dynamically re-skinning the GUI canvas between Graphite (`#0D1419`) and Obsidian (`#000000`) and reflecting the active accent color in real time.
- **Expanded Tab 5 ("Ecosystem & Apps")**: Provides per-application `Restore Backup` buttons, `Restore All Backups`, live profile/accent sync badges, and an interactive Flatpak Theme Override card.
- **CLI & GUI Power Tools**: Full support for Reduced Motion orchestration (`noxforge-ctl motion`), 5-variant Wallpaper Suite switching (`noxforge-ctl wallpaper`), and portable JSON preset export/import (`noxforge-ctl export` / `import`).

### 5. Doctor Schema 11 & Packaging Parity
- **Doctor Schema 11**: Upgraded `tools/noxforge-doctor` with automated checks for `noxforge_core.py` availability, GTK 3/4/Libadwaita `@import` and `@accent_color` chain coherence (`gtkChainStatus`), and reversible ecosystem state/backup integrity (`ecosystemState`).
- **Packaging Parity**: Updated `CMakeLists.txt`, `packaging/noxforge.spec`, `packaging/arch/PKGBUILD`, `scripts/install.sh`, `scripts/uninstall.sh`, `scripts/uninstall-system.sh`, and `scripts/build_store_packages.py` to stage and clean `noxforge_core.py`.
- **Zero-Regression Verification**: Comprehensive contract verification in `tests/test_v18_contracts.py`.

## Installation & Verification

### Fedora 44 (COPR)

```bash
sudo dnf copr enable loofitheboss/noxforge
sudo dnf install --refresh noxforge
noxforge-ctl status
```

### Portable Edition (User-Local)

Download `noxforge-18.0.0-portable.tar.xz` and `SHA256SUMS` from the GitHub Release:

```bash
tar -xJf noxforge-18.0.0-portable.tar.xz
cd noxforge
./scripts/install.sh --user
noxforge-doctor --json
```

### Diagnostics & Health Check

```bash
noxforge-doctor
noxforge-ctl status
noxforge-ctl ecosystem status
```
