# NoxForge 5.0.0

NoxForge 5.0.0 evolves Industrial Precision into a complete, measurable dark
visual system for Fedora KDE 44, Plasma 6.7+, Qt 6.11 and Wayland.

## Visual system

- Schema-v4 semantic design tokens with complete interaction-state, contrast,
  elevation, overlay, shadow and reduced-motion contracts.
- Expanded native Qt 6 control rendering with LTR/RTL geometry, high-DPI
  coverage, safe `QCommonStyle` fallbacks and authentic widget galleries.
- All 43 targeted Plasma widget families generated from versioned semantic
  recipes and qualified across states, panel edges and four scale factors.
- Original 16:9 and ultrawide wallpapers, 185 scalable system icons, 196
  optical variants, physical multi-size cursors and 32 normalized sounds.
- Refined SDDM, Splash, Logout, KWin TabBox and Aurorae surfaces with bounded
  text, keyboard structure, RTL layouts and reduced-motion behavior.

## Qualification

- The authoritative source/archive/RPM release gate passes 90 Python tests,
  18 CTest cases, QML lint, deterministic archive generation and `rpmlint`
  with zero errors and zero warnings.
- AddressSanitizer and UndefinedBehaviorSanitizer pass all 18 CTest cases.
- Accessibility review covers contrast, system fonts, keyboard/RTL structure,
  scale compositions, reduced motion and non-color state indicators.
- Gallery startup, control rendering and QML first-frame medians remain within
  the ten-percent Phase 0 performance budget.
- Isolated KWin/Plasma Wayland qualification passes theme application, exact
  panel preservation, all panel edges, two outputs, shell artwork, required
  icon clarity and real Qt composition at 100 and 140 percent.

## Honest limitations

Hardware-composited blur, injected keyboard and pointer transitions, live RTL,
a held visible Alt+Tab cycle, isolated audio routing, production splash
integration and real SDDM authentication or power actions remain explicitly
blocked by the available environment. Offscreen evidence is not promoted to
live evidence.

## Installation

Enable `loofitheboss/noxforge` on Fedora 44 and install `noxforge`, then run
`rpm -V noxforge` and `noxforge-doctor`. Package installation and removal do
not apply the theme, change panels, activate SDDM, clear caches or restart
Plasma. Select NoxForge explicitly in System Settings.
