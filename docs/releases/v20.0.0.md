# NoxForge 20.0.0

NoxForge 20.0.0 (**Kinetic Iconography, Multi-Level Status Engine & Ecosystem v3**) is an original MIT-licensed visual system for Fedora 44/45 and Arch KDE Plasma 6.8+ and Qt 6.11 on Wayland.

## Highlights

- **Kinetic Iconography & Optical Icon Matrix**:
  - **10%/20%/25% Multi-Level Status Icon Engine**: Deterministic SVGs for battery charging/discharging, Wi-Fi, signal, brightness, microphone, and volume (including mute & overdrive) bound to KDE Plasma `ColorScheme` CSS classes.
  - **True 16x16 & 22x22 Optical Sizing**: 684 optical icons (342 `16x16` + 342 `22x22`, `2px` and `1.5px` strokes) alongside 404 scalable vector icons (`icons/NoxForge/scalable`) with synchronized `index.theme` definitions.
  - **16-Frame Sprite Animations**: Native sprite SVGs (`process-working.svg`, `process-syncing.svg`) across `animations/22`.
  - **Dynamic Desktop Theme Icon Sheets**: 8 Plasma Desktop Theme icon sheets each for Graphite and Obsidian (battery, audio, network, emblem, system-tray).
- **Control Center v5 & Kinetic Icon Studio**:
  - Live animated `process-working` preview, Battery 0–100% / Wi-Fi / Volume interactive level slider, `16px`/`22px`/`scalable` optical toggle, and WCAG AA contrast validation.
  - CLI control via `noxforge-ctl icons [--accent hex] [--optical 16|22|auto] [--reset]`.
  - Integrated Flatpak GTK/Qt sandbox theme & icon override manager (`noxforge-ctl flatpak --enable|--disable|--status`).
- **Plasma 6.8 Union Style Engine & Lock Screen Forge Status Pill**:
  - Enhanced `union/styles/noxforge` and `union/styles/noxforge-obsidian` with multi-state SVG button/checkbox/radio icon masks, focus glow rings, and `QProxyStyle`/Kirigami token harmony.
  - Token-bound **Forge Status Pill** inside the Plasma 6.8 Lock Screen showing live network and battery percentages with `reducedMotion` support.
- **Terminal & Dev Ecosystem v3**:
  - Four new reactive themes managed cleanly with `.noxforge.bak` backups and `ecosystem-state.json`: **Yazi** (`.toml`), **Lazygit** (`.yml`), **Zellij** (`.kdl`), and **Tmux** (`.conf`), bringing full ecosystem support to 18 applications.
- **Doctor Schema 13**:
  - Extended `noxforge-doctor --json` with `iconLevelMatrix`, `animations`, `ecosystemState`, `gtkChainStatus`, and `unionStyleStatus` checks.

## Fedora installation

Install RPM packages from the [COPR repository](https://copr.fedorainfracloud.org/coprs/loofitheboss/noxforge/):

```bash
sudo dnf copr enable loofitheboss/noxforge
sudo dnf install noxforge
```

## Portable installation

Download `noxforge-20.0.0-portable.tar.xz` and `SHA256SUMS` from the release assets:

```bash
sha256sum -c SHA256SUMS --ignore-missing
tar -xJf noxforge-20.0.0-portable.tar.xz
cd noxforge-20.0.0-portable
./install-portable.sh --apply
```
