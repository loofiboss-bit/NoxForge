# NoxForge 10.0.0 — Everyday Precision

NoxForge 10 improves everyday readability and diagnostics while preserving the
graphite palette, electric lime, Forge Notch, system fonts and motion timings.

## Highlights

- Doctor JSON schema 3 reports ordered component paths, effective and shadowed
  copies, structured issue codes, unknown metadata and edition-specific advice.
- Isolated diagnostics reject metadata, plugins and auxiliary markers outside
  the requested root, including symlinks. Component-only installs are supported.
- Keyboard focus remains visible on selected items. Qt surface strokes, popup
  contrast and expanded TabBox labels are more reliable at fractional scales.
- Disabled text avoids compounded opacity; generated and rendered contrast
  checks cover the existing semantic surfaces.
- System removal handles a final CMake manifest entry without a trailing newline.
- Six neutral-profile Wayland captures and automatic media provenance/dimension
  checks replace stale presentation references. The removed PLM image stays removed.

## Editions and installation

[KDE Store](https://store.kde.org/p/2367662) provides component archives; the
Global Theme coordinates separate components and is not a complete one-click
installer. The portable archive installs user-local components and doctor.
Both use Breeze application controls. The complete Fedora package adds the
native Qt style and system components:

```bash
sudo dnf copr enable loofitheboss/noxforge
sudo dnf install --refresh noxforge
noxforge-doctor --json
```

Verify downloads against `SHA256SUMS`. Installation never applies the theme,
changes panels or wallpaper, or switches the display manager. PLM integration
remains standard wallpaper integration; SDDM is an optional compatibility theme.

## Qualification boundary

Local qualification includes 117 passing Python tests (9 skipped), 72 passing
CTest cases on Fedora and 72 on a digest-pinned Arch environment, four sanitizer
probes, QML checks, six offscreen scales, 40 composited contrast cases, deterministic
archives and RPM validation. Actual staged and Fedora RPM v9→v10→v9 cycles preserve
configuration bytes. The canonical release workflow reruns the automated gate on
the exact tag; its attached evidence identifies that commit.

Physical login/PAM, audio, pointer/input, mixed physical displays, the complete
live scale/RTL/motion matrix, live Arch login and pacman lifecycle remain pending.
They are not inferred from offscreen tests or isolated Fedora Wayland images.
